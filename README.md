# 🏒 HOCKEY PULSE

**AI-аналитика хоккея КХЛ и НХЛ**  
*Меньше интуиции. Больше цифр.*

HOCKEY PULSE — экспериментальный Telegram-бот для изучения хоккейных матчей, коэффициентов и доступной спортивной статистики.

## Возможности текущей версии

- 🇺🇸 **НХЛ:** сбор ближайших матчей с доступными коэффициентами, сравнение рыночной оценки с простой моделью на основе разницы голов и формы за последние 10 матчей.
- 📰 **Новости:** попытка получить релевантные спортивные заголовки и использовать Gemini для осторожной корректировки оценки.
- 🇷🇺 **КХЛ:** ручной анализ матча по введённым коэффициентам; при настроенном Gemini формируется дополнительный комментарий ИИ.
- ⏰ **Дайджест:** отдельный режим для отправки ежедневного сообщения.
- 💬 **Telegram:** команды `/start`, `/сегодня`, `/кф`, `/помощь`, `/id`.

> **Статус:** проект находится в тестовом режиме. Публичный доступ, постоянная история прогнозов, полноценная статистическая модель КХЛ и интерактивная история результатов пока не реализованы.

## Команды

| Команда | Назначение |
|---|---|
| `/start` | Приветствие и меню |
| `/сегодня` | Аналитика ближайших матчей НХЛ |
| `/кф Хозяева - Гости 2.10 1.75` | Разбор матча КХЛ по введённым коэффициентам |
| `/помощь` | Справка |
| `/id` | Показать Telegram chat ID для настройки собственного экземпляра |

Кнопка КХЛ использует **ручной ввод коэффициентов**. Она не означает, что автоматический сбор линии КХЛ уже доступен.

## Настройка

Требуется Python 3.10+ и зависимости:

```bash
pip install requests
```

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `TELEGRAM_TOKEN` | Токен Telegram-бота |
| `TELEGRAM_CHAT_ID` | Разрешённый chat ID для текущего закрытого режима |
| `ODDS_API_KEY` | Ключ The Odds API для коэффициентов НХЛ |
| `GEMINI_API_KEY` | Необязательный ключ Gemini для анализа новостей |
| `GEMINI_MODEL` | Необязательная модель Gemini; по умолчанию `gemini-flash-latest` |
| `MODE` | `poll` для обработки команд или `digest` для дайджеста |

Не добавляйте токены и API-ключи в исходный код или публичные коммиты. Для GitHub Actions используйте **Settings → Secrets and variables → Actions**.

## Ограничения и ответственное использование

- Вероятности — оценки модели, а не гарантии результата.
- Простая модель НХЛ требует проверки на исторических данных и калибровки.
- Оценка КХЛ пока не является полноценной статистической моделью.
- Данные о составах, травмах и стартовых вратарях могут отсутствовать или быть устаревшими.
- Проверяйте коэффициенты и время обновления самостоятельно; не ставьте деньги, которые не можете позволить себе потерять.
- Бот не предоставляет финансовых гарантий и не должен восприниматься как замена самостоятельной оценке риска.

## Постоянный хостинг (подготовка)

Для постоянно работающего экземпляра используйте контейнер из `Dockerfile` с командой `python bot.py` и переменной `MODE=serve`.

Обязательные переменные хостинга:
- `TELEGRAM_TOKEN` — токен @BotFather (только в защищённых variables/secrets).
- `TELEGRAM_CHAT_ID` — Telegram ID владельца, которому отправляется ежедневный дайджест в 08:00 МСК.
- `ODDS_API_KEY` — ключ The Odds API.
- `GEMINI_API_KEY` — необязательный ключ Gemini.

Дополнительные переменные:
- `MODE=serve` — непрерывный long polling и ежедневный дайджест.
- `PUBLIC_MODE=false` — безопасное значение по умолчанию; публичные команды аналитики не включены.
- `USER_COOLDOWN_SECONDS=30` — минимальный интервал между аналитическими запросами одного пользователя.

**Публичный режим не включать до проверки деплоя.** Перед открытием доступа проверьте токены, расходы/лимиты внешних API, журналы ошибок и защиту от злоупотреблений. Текущий дайджест отправляется владельцу; рассылка подписчикам потребует отдельной функции подписки и хранения списка пользователей.

### Важно о бесплатном хостинге

Бесплатные веб-инстансы некоторых платформ могут засыпать и перезапускаться; для гарантированного постоянного процесса обычно нужен always-on инстанс. Сначала проверьте ограничения бесплатного плана выбранного провайдера.
